# 孵化事务所 · AI 伙伴孵化大会

一个像素风格的活动小游戏：选择蛋、温度和孵化室，孵化伙伴并获得分数。支持正式活动、自由试玩、排行榜和组织者后台。

## 角色素材说明

为了明确素材使用范围，本公开版本的 65 张角色动作图是同一套原创占位图，**不是活动网站使用的角色插画**。程序与占位图可按本仓库 MIT 许可证使用；角色设定、名称以及第三方作品或商标的权利不因代码许可而改变。

活动版本的角色设定参考了 [AI 娘设定图库](https://aigengtu.com/refs) 中所列的创作者；其中部分来源有非商业及相同方式共享等限制，另有来源需单独确认授权。活动版角色插画和原始参考图未包含在仓库内。

替换方法：准备自己拥有使用权的透明 PNG 动作图，放在 `assets/monsters/`，依照 `M01-actions.png` 至 `M65-actions.png` 命名。每张图为 **1536 × 1024 像素，4 列 × 2 行，共 8 帧**，单帧 384 × 512 像素。帧顺序为待机、眨眼、招呼 1、招呼 2、行走 1、行走 2、亲近回应、专属互动。若新素材的主体范围不同，需要同时调整 `character-actions.mjs` 中对应的帧裁切 / 偏移，以免人物被裁掉。

## 本地启动

需要 Node.js 24，项目不需要安装第三方依赖：

```bash
node tools/prepare-activity.mjs
node tools/run-activity-local.mjs
```

访问 <http://127.0.0.1:4390/>；排行榜在 `/leaderboard`，管理页在 `/admin`。首次准备时会在本项目的 `private/` 中生成新管理口令和空白数据库；数据库与已有线上活动独立。管理口令可在本机的 `private/活动管理访问说明.txt` 查看，请勿提交或分享该目录。

## 活动规则

首次正式孵化由服务器随机生成角色与分数，并按自填姓名保存；同名仅保留最早的一次正式结果。之后的试玩不改变排行榜。排行榜显示脱敏姓名，完整姓名及 CSV 仅在管理后台查看。姓名不做身份核验；项目不包含自动发奖功能。

## 检查

```bash
npm test
```

`catalog.mjs` 和 `character-actions.mjs` 定义角色目录与动作，`engine.mjs` 定义随机规则，`server/` 提供活动接口和 SQLite 存储，`tests/` 验证规则及活动流程。仓库不包含活动参与者数据或管理凭据。正式部署时应自行配置独立域名、HTTPS、持久化存储和新的管理凭据。
